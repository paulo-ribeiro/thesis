# GAMP: Graphical Analysis of Mapper Parameters 

GAMP is designed to systematically explore and visually analyze how different parameter configurations affect the topological structures generated by the Mapper algorithm. This specific version is optimized to identify recurrent gene mutation co-occurrence modules in Diffuse Large B-Cell Lymphoma (DLBCL) datasets.

---

## How to Run

1. Open `GAMP.ipynb` in **Google Colab**.
2. Upload your preprocessed DLBCL mutation data in a MAF  format.
3. Run all cells sequentially to export complete tables of metrics and visual PDF reports to the `Output/` folder.
